# 禅道Max 使用说明

官网: https://murphyyi.com

## 1. 应用简介

禅道Max 是一款基于 Wails 和 Vue 开发的禅道项目管理系统辅助工具，提供了 Bug 查询、需求查询、任务查询和工时统计等核心功能，帮助团队更高效地管理项目。

## 2. 系统初始化

首次使用禅道Max 时，需要进行系统初始化。

### 2.1 初始化步骤

1. **打开应用**：启动禅道Max 应用
2. **输入登录信息**：在初始化引导页面填写禅道地址、账号、密码，选择认证域（禅道本地 `local` / 受限实例 SSO `kydc`）
3. **登录**：点击 "登录" 按钮，系统会调用禅道接口验证凭据
4. **登录成功**：系统自动跳转到主页面
5. **测试连接**：可选择点击 "测试禅道连接" 按钮，验证与禅道系统的连接状态

## 4. 功能模块使用

### 4.1 产品与项目选择

在使用任何功能模块前，需要先选择产品和项目：

1. **选择产品**：在顶部栏的产品选择器中选择一个产品
2. **选择项目**：产品选择后，项目选择器会自动加载该产品下的项目，选择一个项目

### 4.2 Bug 查询

Bug 查询模块允许您查看和筛选 Bug 列表。

#### 功能特点：
- **多维度筛选**：支持按指派人、状态、时间范围筛选
- **详细信息**：查看 Bug 的详细信息，包括标题、状态、严重程度、指派人等
- **导出功能**：支持导出选中的 Bug 为 Excel 文件
- **禅道链接**：点击 Bug 标题可直接打开禅道中的对应 Bug 页面

#### 使用步骤：
1. 在左侧导航栏点击 "Bug 查询"
2. 选择产品和项目
3. 设置筛选条件（可选）
4. 点击 "查询" 按钮
5. 查看 Bug 列表
6. 可选择 Bug 后点击 "查看详情" 或 "导出"

### 4.5 工时统计

工时统计模块提供了直观的工时数据统计和分析。

- **工时明细**：显示详细的工时流水记录
- **数据缓存**：支持数据缓存，提高查询速度

#### 使用步骤：
1. 在左侧导航栏点击 "工时统计"
2. 选择产品

4. 设置其他筛选条件（可选）
5. 点击 "查询统计" 按钮
6. 查看统计结果和图表
7. 可在工时流水明细表中搜索和排序

### 4.6 MCP 对接指南

MCP 对接指南模块提供了 MCP 对接的相关文档和说明，支持两种传输模式、运行时热重载与 Token 鉴权。

#### 传输模式

| 模式 | 入口 | 适用场景 |
|------|------|----------|
| **stdio** | `zentao-max-mcp` 独立进程 | AI 工具（Claude / Cursor / Claude Code 等）子进程调用 |
| **http** | `zentao-max` HTTP server（默认端口 12345） | Web 应用、远程调用、跨机器访问 |
| **both** | HTTP 入口额外启动后台 stdio 监听 | 同时需要两种传输 |

构建 stdio 独立入口：

```bash
cd backend && make build-mcp    # 产物：backend/zentao-max-mcp
```

#### MCP 配置（config.yaml 或环境变量）

```yaml
mcp:
  enabled: true              # 是否启用 MCP 服务
  transport: http            # http | stdio | both
  token: ""                  # 鉴权 Token，空表示不鉴权
  read_only: false           # 只读模式（禁止写操作，当前全查询预留）
  actions: []                # action 白名单，空表示允许全部
```

对应环境变量（前缀 `ZENTAO_MAX_`）：`ZENTAO_MAX_MCP_ENABLED`、`ZENTAO_MAX_MCP_TRANSPORT`、`ZENTAO_MAX_MCP_TOKEN`、`ZENTAO_MAX_MCP_READ_ONLY`、`ZENTAO_MAX_MCP_ACTIONS`。

#### 运行时热重载（无需重启）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/mcp/status` | 查询当前模式状态 |
| GET | `/api/v1/mcp/config` | 查询配置快照（Token 不返回明文） |
| PUT | `/api/v1/mcp/config` | 部分更新（enabled / readOnly / token / actions） |

示例：

```bash
# 临时禁用 MCP
curl -X PUT http://localhost:12345/api/v1/mcp/config \
  -H "Content-Type: application/json" -d '{"enabled": false}'

# 设置 Token 鉴权（立即生效）
curl -X PUT http://localhost:12345/api/v1/mcp/config \
  -H "Content-Type: application/json" -d '{"token": "your-secret"}'
```

> ⚠️ 管理 API 当前未加额外鉴权，生产环境请配合反向代理鉴权或网络隔离。

#### 使用步骤：
1. 在左侧导航栏点击 "MCP对接指南"
2. 查看对接相关文档，状态卡实时显示当前 MCP 模式状态

## 5. 常见操作

### 5.1 导出数据

在 Bug 查询模块中，您可以导出选中的 Bug 为 Excel 文件：

1. 在 Bug 列表中选择一个或多个 Bug
2. 点击 "导出" 按钮
3. 系统会生成并下载 Excel 文件

### 5.2 查看禅道原始页面

在 Bug、需求、任务列表中，点击标题链接可以直接打开禅道中的对应页面：

1. 在列表中找到需要查看的项
2. 点击标题链接
3. 系统会在浏览器中打开禅道的对应页面

### 5.3 重置筛选条件

在各个查询模块中，您可以重置筛选条件：

1. 点击 "重置" 按钮
2. 所有筛选条件会被清空

## 6. 系统要求

- **操作系统**：支持 Windows、macOS、Linux
- **禅道版本**：兼容禅道 12.0 及以上版本
- **网络连接**：需要与禅道服务器保持网络连接

## 7. 故障排除

### 7.1 初始化失败

- **原因**：可能是配置文件不正确或网络连接问题
- **解决方法**：检查配置文件是否正确，确保网络连接正常，重新尝试初始化

### 7.2 数据加载失败

- **原因**：可能是网络连接问题或禅道服务器响应缓慢
- **解决方法**：检查网络连接，稍后重试

### 7.3 导出失败

- **原因**：可能是数据量过大或浏览器兼容性问题
- **解决方法**：减少选择的项数量，或尝试使用不同的浏览器
